### 1. 题目内容翻译

一个监控设备会产生一组数值测量数据，这些数据是在相等的时间间隔内收集的。

题目定义了两个概念：

**概念一：Exceedance（超过阈值）**

当某个数值严格大于固定阈值（Threshold）时，就称为一次超过阈值的情况。

例如，阈值为 15：

- 16：超过阈值。
- 20：超过阈值。
- 15：没有超过阈值。
- 10：没有超过阈值。

注意：必须严格大于 15，而不是大于或等于 15。

**概念二：Abrupt Change（突变）**

当两个相邻测量值之间的绝对差值严格大于指定的跳变限制（Jump Limit）时，就称为一次突变。

例如，`jump_limit = 10`：

- 两个数值相差 12：属于突变。
- 两个数值相差 10：不属于突变。
- 两个数值相差 5：不属于突变。

### 2. 编写函数

实现：

```python
analyse_sensor(readings, threshold, jump_limit)
```

函数必须返回一个包含三个整数的列表，顺序如下：

```python

 longest_consecutive_exceedance_run,
 number_of_abrupt_changes]
```

三个返回值的含义：

| 返回位置 | 含义 |
|---|---|
| 第一个数字 | 超过阈值的测量值总数量 |
| 第二个数字 | 连续超过阈值的最长次数 |
| 第三个数字 | 相邻数据中发生突变的总次数 |

### 3. 具体任务要求

#### （a）计算超过阈值的总次数
统计所有严格大于 `threshold` 的测量值。

#### （b）寻找最长连续超标次数
找出连续超过阈值的最长数据段。如果某个测量值等于阈值，也会中断连续记录。

例如：

```python
[16, 18, 15, 21, 22]
```

阈值为 15：

- 16、18：连续两次超过阈值。
- 15：没有超过阈值，因此中断。
- 21、22：连续两次超过阈值。

最长连续超标次数为 2。

#### （c）统计突变次数
计算相邻两个测量值之间的绝对差值，统计所有绝对差值严格大于 `jump_limit` 的相邻数据对。

不允许使用外部库，但允许使用 `abs()` 函数。

#### （d）处理特殊情况

- 输入列表只有一个测量值。

并展示相应测试结果。

## 四、Question 3 – Run-Length Encoding（20分）
### 游程编码 / 连续字符压缩

### 1. 题目内容翻译

游程编码（Run-Length Encoding，简称 RLE）是一种字符串压缩方法。它通过将连续出现的相同字符替换为：

**字符本身 + 该字符连续出现的次数。**

例如：

原始字符串：

```text
AAABB
```

压缩之后：

```text
A3B2
```

解释：

- A 连续出现 3 次。
- B 连续出现 2 次。

### 2. 编写函数

实现一个名为：

```python
encode_runs(text)
```

的函数。

### 3. 具体任务要求

#### （a）从左向右扫描字符串
必须从字符串最左边开始，逐个检查字符。统计连续出现的相同字符数量，并返回编码后的字符串。

注意：必须返回字符串，不能只是打印结果。

#### （b）确保所有字符都被正确处理

需要满足以下要求：

1. 最后一组连续字符也必须被编码，不能遗漏。
2. 即使某个字符只出现一次，也必须记录次数 1。
3. 大写字母和小写字母被视为不同的字符。

例如，`A` 和 `a` 是两个不同的字符。

假设输入只包含英文字母。

#### （c）测试函数

| 输入字符串 | 预期返回结果 |
|---|---|
| `AAABCCCCDD` | `A3B1C4D2` |
| `aAAbbBA` | `a1A2b2B1A1` |
| `Z` | `Z1` |

题目禁止使用：

- 字典。
- 正则表达式。
- 推导式。
- 辅助程序包。

### 4. 额外解释要求

简要解释：为什么简单的字符总频率统计（Total Frequency Count）不能完成这项任务？

例如：

```text
AABAA
```

这里 A 总共出现三次，但 A 实际上分布在两个不同的连续区段：

```text
AA | B | AA
```

所以正确编码是：

```text
A2B1A2
```

而不是简单地把 A 的总次数合并。

## 五、Question 4 – Loan Repayment Simulation（20分）
### 贷款还款模拟

### 1. 题目内容翻译

一家金融机构希望估算：如果客户每个月按照固定金额偿还贷款，需要多长时间才能还清未偿还的贷款余额。

本题只能使用 Python 基础知识，包括：

- 算术运算。
- 条件判断。
- 函数。
- 循环。

编写一个函数：

```python
simulate_loan(balance, annual_rate, monthly_payment, max_months)
```

参数含义：

| 参数 | 中文含义 |
|---|---|
| `balance` | 当前贷款余额 |
| `annual_rate` | 年利率 |
| `monthly_payment` | 每月还款金额 |
| `max_months` | 最大模拟还款月数 |

假设所有输入都是数字，并且：

- `balance > 0`
- `annual_rate >= 0`
- `monthly_payment > 0`
- `max_months` 是正整数。

年利率按照百分比计算。例如，12 表示年利率为 12%。

### 2. 每个月的贷款计算规则

题目规定：每个月必须先计算利息，然后再扣除还款金额。

#### 第一步：计算利息

公式：

\[
interest=current\_balance\times\frac{annual\_rate}{1200}
\]

例如，当前贷款余额为 RM1000，年利率为 12%：

\[
1000\times\frac{12}{1200}=10
\]

因此当月利息为 RM10。

#### 第二步：计算实际还款金额

实际还款金额取以下两个数值中较小的一个：

1. 每月固定还款金额。
2. 当前贷款余额加上当月利息。

即：

\[
amount\_paid=\min(monthly\_payment,\ current\_balance+interest)
\]

注意：最后一次还款不能超过实际欠款金额。

#### 第三步：更新贷款余额

\[
new\_balance=current\_balance+interest-amount\_paid
\]

### 3. 具体任务要求

#### （a）实现贷款计算
计算每个月产生的利息、实际支付的金额和更新后的贷款余额。确保最后一次还款不会超过实际欠款。

#### （b）使用循环模拟还款过程
使用循环模拟最多 `max_months` 个月的还款。

需要记录：

- 已经还款的月份数量。
- 累计产生的总利息。

如果贷款余额变为零，必须立即停止模拟。

#### （c）识别无法正常偿还贷款的情况
需要检测贷款余额是否无法减少。

如果某个月的还款金额小于或等于当月利息，则停止模拟，并设置状态：

```python
'INSUFFICIENT PAYMENT'
```

否则，根据实际还款情况设置状态：

| 状态 | 含义 |
|---|---|
| `PAID OFF` | 贷款已经全部还清 |
| `LIMIT REACHED` | 已达到最大模拟月份，但仍有未偿还余额 |
| `INSUFFICIENT PAYMENT` | 每月还款金额不足以使贷款余额减少 |

最终必须返回：

```python
[status, months_used, remaining_balance, total_interest]
```

四个返回值分别代表：

1. 还款状态。
2. 实际使用的还款月份。
3. 剩余贷款余额。
4. 累计支付的总利息。

#### （d）使用三组数据进行测试


展示还款状态、还款月份、剩余金额和总利息。所有金额必须保留两位小数。

### 复习建议

不要只记住已经完成的代码。尤其是 Q2、Q4 和 Q5，要真正理解：

1. 计数器如何变化？
2. 循环什么时候停止？
3. 不同条件下如何更新结果？
4. 如何处理空列表、单元素、无法还款和没有可行组合等边界情况？

这些才是这份作业真正考查的编程能力。

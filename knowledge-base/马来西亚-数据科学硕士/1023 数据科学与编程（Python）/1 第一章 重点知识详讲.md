## 2. Hello World：你的第一个程序

### 原文逐句翻译

**Your first program: Print!**
你的第一个程序：打印（输出）！

**Python can handle strings of letters that are enclosed in quotation marks like:**
Python 可以处理放在引号中的字符文本，例如：

```python
"Hello World"
'Hello World'
```

**One of the simplest programs is print, which works like the following:**
最简单的程序之一是 `print`，它的使用方式如下。

### 代码讲解

```python
print('Hello World!')
```

输出：

```text
Hello World!
```

解释：
- `print()` 是输出指令。
- 括号里的内容是要显示的内容。
- `'Hello World!'` 是字符串，因为它被引号包围。

下面几种写法有什么区别？

```python
'Hello World!'
"Hello World!"
print("Hello World!")
print("'Hello World!'")
```

前三种中，单独写字符串时，Notebook 会显示字符串的表示形式；使用 `print()` 则直接输出内容。第四种会把内部的单引号也作为文本输出。

下面这种写法是错误的：

```python
print(Hello World!)
```

原因：文字没有放在引号中，Python 会把 `Hello` 当作变量名称来理解，而不是普通文本。

**记忆：要输出普通文字，必须用单引号或双引号包起来。**

## 3. Arithmetic：算术运算

### 原文逐句翻译

**Python can also handle numbers, and basic arithmetic using the following functions.**
Python 也可以处理数字，并使用下面这些运算符进行基本算术运算。

| 符号 | 英文 | 中文含义 | 示例 |

**记忆：括号里的内容先计算；没有括号时，乘除通常先于加减。**

## 4. Integers vs. Float：整数与浮点数

### 原文逐句翻译

**Python allows you to work with both integers (int) and numbers containing decimals (float).**
Python 允许你处理整数（`int`）和带小数的数字（`float`）。

**Of course, every integer can be represented as a float, but there are some things you can do with integers that you cannot do with floats that mostly have to do with precision.**
整数可以表示成浮点数，但整数和浮点数在精度等方面存在差异，因此有些操作表现并不相同。

**Python can tell automatically if a number is an int or a float, though you can override this as you see fit.**
Python 可以自动判断一个数字是整数还是浮点数；你也可以根据需要主动转换类型。

### 什么是 int 和 float？

```python
10       # int，整数
10.0     # float，浮点数
2.7      # float，浮点数
```

- `int`：没有小数部分的整数。
- `float`：带小数的数值。

### `type()`：查看数据类型

```python
print(type(10))
print(type(10.))
```

输出：

```text
<class 'int'>
<class 'float'>
```

`type()` 就像检查一个东西的类别：它告诉你当前数据属于哪一种类型。

### 重要运算示例

```python
print(10 / 3)
print(10 % 3)
print(float(10) / 3)
print(13.0 / 3.5)
print(13.0 // 3.5)
print(round(7.5))
```

逐句解释：
- `10 / 3`：普通除法，得到带小数的结果。
- `10 % 3`：10 除以 3 的余数是 1。
- `float(10)`：把整数 10 转换为浮点数 10.0。
- `13.0 / 3.5`：普通除法。
- `13.0 // 3.5`：向下取整除法。
- `round(7.5)`：四舍五入到整数；具体边界规则在 Python 中采用“舍入到偶数”的规则，因此 `round(7.5)` 的结果是 8。

### 一个需要特别说明的课件细节

课件的文字说明中有一句把整数除法描述为“丢掉余数”，但同一份课件使用 Python 3 的 `9/4` 示例。Python 3 中：
- `/` 是普通除法，`9/4` 得到 `2.25`；
- `//` 才是向下取整除法，`9//4` 得到 `2`；
- `%` 用于取得余数，`9%4` 得到 `1`。

学习和写作业时，以 Python 3 实际运算符行为为准。

### 取余数 `%` 的直观理解

```python
print(9 / 4)
print(9 // 4)
print(9 % 4)
```

结果：

```text
2.25
2
1
```

想象 9 个苹果，每 4 个装一袋：
- 可以装满 2 袋；
- 剩下 1 个；
- 所以 `9 // 4` 是 2，`9 % 4` 是 1。

## 5. Float arithmetic：浮点数运算

### 课件例子

```python
print(5.5 + 2.2)
print(5.5 - 2.2)
print(5.5 * 2.2)
```

结果大致为：

```text
7.7
3.3
12.100000000000001
```

### 为什么乘法结果不是刚好 12.1？

课件原文说明：

**The output is in the very nature of binary floating-point: this is not a bug in Python, and it is not a bug in your code either.**
这种输出是二进制浮点数本身的特性，并不是 Python 的错误，也不是你的代码写错了。

浅显理解：
计算机用二进制保存小数，有些十进制小数无法被二进制精确表示，所以内部保存的数可能是非常接近 12.1 的值。

### 用 `format()` 控制显示的小数位

```python
print(format(5.5 * 2.2, '.2f'))
```

输出：

```text
12.10
```

解释：
- `format()`：格式化显示。
- `'.2f'`：以浮点数形式显示，并保留小数点后两位。

继续看：

```python
print(5.5 / 2.2)
print(5.5 // 2.2)
print(5.5 ** 2.2)
print(5.5 < 2.2)
print(5.5 != 2.2)
```

含义：
- `/`：除法。
- `//`：向下取整除法。
- `**`：幂运算。
- `<`：小于，结果为布尔值。
- `!=`：不等于，结果为布尔值。

## 6. Variables：变量

### 原文逐句翻译

**A name that is used to denote something or a value is called a variable.**
用来表示某个东西或某个值的名称，叫作变量。

**This is how a computer stores data, by assigning it to a variable!**
计算机通过把数据赋给变量的方式来保存数据。

**In Python, variables can be declared and values can be assigned to it as follows:**
在 Python 中，可以按照下面的方式创建变量并给变量赋值。

### 代码示例

```python
b = -10
c = 2.7

print(b)
print(c)
print(b + c)

print(type(b))
print(type(c))
```

逐句理解：
- `b = -10`：创建变量 `b`，保存数字 -10。
- `c = 2.7`：创建变量 `c`，保存数字 2.7。
- `print(b)`：显示 b 的值。
- `print(c)`：显示 c 的值。
- `print(b+c)`：把两个变量的值相加。
- `type(b)`：查看 b 的数据类型。
- `type(c)`：查看 c 的数据类型。

### 类型转换

```python
b = float(b)
c = int(c)
```

- `float(b)`：把 b 转换成浮点数，例如 `-10.0`。
- `int(c)`：把 c 转换成整数。`int(2.7)` 得到 2，不是四舍五入，而是直接去掉小数部分。

**特别区分：**
- `int(2.9)` → `2`
- `round(2.9)` → `3`

### 多个变量赋相同的值

课件原文：**Multiple variables can be assigned with the same value.**
多个变量可以被赋予相同的值。

```python
x = y = 1
print(x, y)
```

结果：

```text
1 1
```

这表示 x 和 y 当前都保存数值 1。

### `id()` 是什么？

课件说明：`id(x)` 返回对象的 identity，可以把它理解为 Python 对象在其生命周期中的身份标识。

```python
id(x)
id(y)
```

如果 x 和 y 指向同一个对象，可能显示相同的 id。

可以把它类比为对象的识别编号。一般写作业不需要使用 `id()`，也不要把 `id` 当作自己的变量名。

### 多重赋值与交换变量

```python
x, y = 2, 3
x, y = y, x
print(x, y)
```

执行过程：
1. 第一行：x=2，y=3。
2. 第二行：交换两者的值。
3. 最终：x=3，y=2。

结果：

```text
3 2
```

这是一种 Python 中简洁的变量交换方式。

### 变量命名规则（课件原文逐条翻译）

1. 变量名称只能包含字母、数字和下划线。变量名可以用字母或下划线开头，但不能以数字开头。
2. 变量名不能有空格，因此通常用下划线代替空格。例如使用 `student_name`，不要使用 `student name`。
3. 不能使用 Python 关键字作为变量名。
4. 变量名称应该有描述性，但不要过长。例如 `mc_wheels` 比 `wheels` 更明确；也不要写得过分冗长。
5. 注意小写字母 `l` 和大写字母 `O`，它们可能与数字 `1` 和 `0` 混淆。

### Quick Exercise 3：变量会变化

课件代码：

```python
guess_this_number = 17
guess_this_number = guess_this_number / 2
guess_this_number = guess_this_number - 5

```

## 7. Strings：字符串

### 原文逐句翻译

**A string is a set of characters.**
字符串是一组字符。

**Strings are used to store data that is text.**
字符串用于保存文本数据。

**In Python, Strings are abbreviated "str" and there are many built-in features that allow you to manipulate those strings.**
在 Python 中，字符串的数据类型简称为 `str`，Python 提供了许多内置功能来处理字符串。

**Strings can be enclosed by either double or single quotes, although single quotes are more common.**
字符串可以用单引号或双引号包围，课件指出单引号更常见。

### 哪些写法是有效字符串？

```python
print('hello')
print("hello")
```

这两种都正确。

下面这些写法存在引号不匹配或语法问题：

```python
'hello"
'hello
"hello'
```

字符串开头和结尾的引号必须匹配。

### 把变量放进输出中

```python
name = 'Suhaila'
age = "48"

print('My name is', name, "and my age is ", age)
```

输出：

```text
My name is Suhaila and my age is 48
```

注意：`name` 是字符串变量，`age` 这里也被引号包围，所以它也是字符串。

### `ord()`：字符对应的编码数值

课件示例：

```python
print(ord('A'))
print(ord('a'))
```

`ord()` 返回字符对应的 Unicode 编码数值。大写 A 和小写 a 的编码不同，因此大小写字符并不相同。

课件还展示了欧元符号 `€` 的例子。不同字符都可以有自己的 Unicode 编码。

### 字符串连接（Concatenation）

课件原文：
- `s + t`：把字符串 s 和字符串 t 连接起来。
- `n * s`：相当于把字符串 s 重复 n 次。

```python
b = 'French'
print(b + 'Fries')
print(b, 'Fries')
```

第一行输出 `FrenchFries`，因为 `+` 是直接连接，不会自动增加空格。
第二行输出 `French Fries`，因为 `print()` 默认会在多个参数之间加空格。

### 字符串不能直接与数字拼接

```python
pi = 3.14
print('pi is approximately: ' + pi)
```

这会报错，因为左边是字符串，右边是浮点数，不能直接用 `+` 拼接。

正确写法之一：

```python
pi = '3.14'
print('pi is approximately: ' + pi)
```

或者先转换成字符串：

```python
pi = 3.14
print('pi is approximately: ' + str(pi))
```

### 字符串重复

```python

```

`a * 2` 表示把 `oleh ` 重复两次。

## 8. String Indexing and Slicing：字符串索引与切片

这是第一份课件非常重要的内容，也是 Assignment 1 Q1、Q3 会用到的基础。

### 原文逐句翻译

**Characters in a string can be accessed using the standard [ ] syntax.**
可以使用标准的方括号 `[]` 语法访问字符串中的字符。

**Python uses zero-based indexing.**
Python 使用从 0 开始的索引。

**This is easiest to think of if you think of each letter as being in its own box.**
最容易理解的方法，是把每个字母想象成放在自己的小格子里。

以 `hello` 为例：

| 字符 | h | e | l | l | o |
|---|---:|---:|---:|---:|---:|
| 正向索引 | 0 | 1 | 2 | 3 | 4 |
| 反向索引 | -5 | -4 | -3 | -2 | -1 |

### 单个字符：`s[i]`

```python
h = 'hello'
print(h[0])
print(h[1])
print(h[-1])
```

结果：

```text
h
e
o
```

- `h[0]`：第一个字符。
- `h[1]`：第二个字符。
- `h[-1]`：最后一个字符。

### 切片：`s[start:end]`

课件原文：

**s[1:4] is 'ell' — chars starting at index 1 and extending up to but not including index 4.**
`s[1:4]` 的结果是 `'ell'`，从索引 1 开始，一直到索引 4 之前，但不包含索引 4。

```python
h = 'hello'
print(h[1:4])
```

结果：

```text
ell
```

**重点：左边包含，右边不包含。**

### 省略起点或终点

```python
print(h[1:])
print(h[:])
print(h[:3])
```

- `h[1:]`：从索引 1 到结尾。
- `h[:]`：从头到尾，得到完整字符串的副本。
- `h[:3]`：从开头到索引 3 之前。

### 终点超过字符串长度

课件原文：

**An index that is too big is truncated down to the string length.**
如果切片的终点索引过大，Python 会将它限制在字符串长度范围内。

```python
print(h[1:100])
```

结果仍然是：

```text
ello
```

### 负数索引与切片

```python
print(h[-1])
print(h[-4])
print(h[:-3])
print(h[-3:])
```

结果：

```text
o
e
he
llo
```

解释：
- `h[-1]`：最后一个字符。
- `h[-4]`：从末尾往前数第四个字符。
- `h[:-3]`：从开头取到倒数第三个字符之前。
- `h[-3:]`：从倒数第三个字符取到末尾。

### 带步长的切片：`s[i:j:k]`

课件原文：
- `s[i]`：字符串 s 中索引为 i 的字符，索引从 0 开始。
- `s[i:j]`：从 i 切到 j，但不包含 j。
- `s[i:j:k]`：从 i 切到 j，每隔 k 个位置取一个字符。

```python
z = 'Jupyter'
print(z[1])
print(z[1:5])
print(z[1:5:2])
```

理解：
- `z[1]`：取一个字符。
- `z[1:5]`：取索引 1、2、3、4。
- `z[1:5:2]`：从索引 1 开始，每次向前跳 2 格，直到索引 5 之前。

### 本节必须掌握

| 写法 | 含义 |
|---|---|
| `s[0]` | 第一个字符 |
| `s[-1]` | 最后一个字符 |
| `s[1:4]` | 索引 1 到 3 |
| `s[:3]` | 开头到索引 2 |
| `s[2:]` | 索引 2 到结尾 |
| `s[:]` | 整个字符串 |
| `s[::2]` | 每隔一个字符取一个 |

## 9. String Index Related Methods：字符串索引相关方法

### 课件原文逐句翻译

**len(s) — length of string s**
`len(s)`：计算字符串 s 的长度。

**s.index(x) — index of the first occurrence of x in string s**
`s.index(x)`：返回 x 在字符串 s 中第一次出现的位置。

**s.find('other') — searches for the given other string within string s, and returns the first index where it begins or -1 if not found.**
`s.find('other')`：在字符串 s 中搜索指定文本，返回它第一次出现的位置；如果找不到，则返回 -1。

课件特别说明：`find()` 搜索的是普通文本，不是正则表达式。

### 示例

```python
data = "You can have data without information"

print(len(data))
print(data.find('data'))
print(data.index('data'))
```

理解：
- `len()` 返回字符总数。
- `find()` 找到文本第一次出现的位置。
- `index()` 也能找到第一次出现的位置。

### `find()` 和 `index()` 的关键区别

```python
text = "hello"

print(text.find("x"))
```

输出：

```text
-1
```

如果使用：

```python
text.index("x")
```

因为没有找到 x，会产生错误。

**记忆：**
- 不确定文本是否存在，通常用 `find()` 更安全。
- 确定文本存在时，可以用 `index()`。
- `find()` 找不到返回 -1；`index()` 找不到会报错。

### 用切片截取内容

课件示例的思路是：
1. 用 `find()` 或 `index()` 找到作者名字的位置。
2. 用切片把作者名字取出来。
3. 用同样方法找到职业描述。
4. 用句号的位置截取引用内容。

例如：

```python

start = quote.find("-")
author = quote[start + 1:]

print(author)
```

输出：

```text
Pythagoras
```

## 14. Procedural Abstraction：过程抽象

## 15. Functions：函数

### 原文逐句翻译

**A function is a block of organized, reusable code that is used to perform a single, related action.**
函数是一段经过组织、可以重复使用的代码，用来完成一个特定的相关任务。

**For example, we can use the same procedure to multiply two numbers, whatever they are.**
例如，无论输入哪两个数字，我们都可以使用同一个过程来计算它们的乘积。

**We then specify the numbers being multiplied as arguments of the function.**
然后，我们把需要相乘的数字作为函数的参数传进去。

**Many functions return a value which you can then use; they can also print something out immediately.**
很多函数会返回一个值，供后续代码继续使用；函数也可以直接打印内容。

### 函数基本结构

```python
def functionname(parameters):
    "Description of the function"
    block_of_code
    return expression
```

逐项解释：
- `def`：定义函数。
- `functionname`：函数名称。
- `parameters`：参数，函数运行时需要接收的数据。
- `:`：表示函数代码块开始。
- 缩进：表示哪些代码属于函数内部。
- `return`：把结果返回给调用者。

### 例子一：只打印，不返回结果

```python
def myPrinter(text):
    print(text)

myPrinter(234)
myPrinter("This is python class")
```

输出：

```text
234
This is python class
```

解释：
- 定义函数时，参数名称叫 `text`。
- 调用 `myPrinter(234)` 时，234 传入 text。
- 函数执行 `print(text)`，把内容显示出来。

课件注释称这种函数为 void，即没有显式返回值。

### 例子二：有返回值的函数

```python
def multiplyer(i, j):
    return i * j

print(multiplyer('hello', 3))
print(multiplyer(4, 3))
print(multiplyer(4, 3) + 1)
```

解释：
- 函数接收两个参数 i 和 j。
- `return i*j` 把两者相乘的结果交还给调用者。
- 字符串乘以整数表示重复字符串，所以 `'hello' * 3` 会得到 `hellohellohello`。
- `4*3` 得到 12。
- `multiplyer(4,3)+1` 得到 13。

### 参数数量必须匹配

```python
multiplyer(23, 24, 5)
```

会报错，因为函数定义只接收两个参数，却传入了三个。

### 把函数返回值保存到变量

```python
def multiplyer(i, j):
    return i * j

b = multiplyer(2, 4)
print(b)
```

结果：

```text
8
```

解释：函数计算出 8，`return` 把 8 交回来，然后变量 b 保存这个结果。

### `print()` 和 `return` 的区别

| `print()` | `return` |
|---|---|
| 把内容显示在屏幕上 | 把结果交回调用者 |
| 主要用于展示 | 结果可以继续计算或保存 |
| 不等于返回结果 | 函数执行到 return 会结束并返回 |

例如：

```python
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b
```

`add_print(2,3)` 会显示 5，但不能直接把它当作函数计算结果继续使用。
`add_return(2,3)` 会返回 5，可以写成 `x = add_return(2,3)`。

## 17. 函数练习：查找第二次出现的位置

课件原文：

**Define a procedure that finds the index of the second instance of a string in a larger string.**
定义一个过程，用来查找某个字符串在较长字符串中第二次出现的位置。

代码：

```python
def find_second(findin, whattofind):
    first_index = findin.find(whattofind)
    print(first_index)
    second_index = findin.find(whattofind, first_index + 1)
    return second_index
```

逐行解释：
1. `findin`：要搜索的大字符串。
2. `whattofind`：要查找的小字符串。
3. `findin.find(whattofind)`：先找第一次出现的位置。
4. `first_index + 1`：从第一次出现位置之后开始继续找。
5. 第二次 `find()` 找到第二次出现的位置。
6. `return second_index`：返回第二次出现的位置。

示例：

```python
find_second('dance, dance, dance everyday', 'dance')
```

第一次出现的位置是 0，第二次出现的位置是 7，因此返回 7。

注意：如果第一次都找不到，`find()` 会返回 -1；课件示例没有进一步处理这种特殊情况。

## 19. Conditional Execution：条件执行

### 原文逐句翻译

**Python does not use { } to enclose blocks of code for if/loops/function etc. like C.**
Python 不像 C 语言那样使用 `{}` 把 if、循环、函数等代码块包起来。

**Instead, Python uses the colon (:) and indentation/whitespace to group statements.**
Python 使用冒号 `:` 和缩进来组织代码语句。

### 通俗理解

Python 非常重视缩进。

```python
if x > 0:
    print("Positive")
```

冒号后面缩进的代码属于 if 的代码块。

如果缩进不正确，程序可能报错，或者代码的执行范围发生变化。

### if：单条件判断

课件原文：

**In order to write useful programs, we almost always need the ability to check conditions and change the behavior of the program accordingly.**
为了编写有用的程序，我们几乎总是需要检查条件，并根据条件改变程序的行为。

**Conditional statements give us this ability.**
条件语句让我们能够实现这种功能。

**The simplest form is the if statement.**
最简单的形式就是 `if` 语句。

```python
if x > 0:
    print("x is positive")
```

翻译：如果 x 大于 0，就输出“x 是正数”。

**The boolean expression after the if statement is called the condition.**
if 后面的布尔表达式叫作条件。

**If the logical condition is true, then the indented statement gets executed.**
如果条件为真，就执行缩进的语句。

**If the logical condition is false, the indented statement is skipped.**
如果条件为假，就跳过缩进的语句。

### if / else：二选一

课件原文：

**A second form of the if statement is alternative execution, in which there are two possibilities and the condition determines which one gets executed.**
第二种形式是选择执行：存在两种可能，由条件决定执行哪一种。

```python
if x % 2 == 0:
    print("x is even")
else:
    print("x is odd")
```

解释：
- `x % 2`：计算 x 除以 2 的余数。
- 如果余数等于 0，说明 x 是偶数。
- 否则，x 是奇数。

**Since the condition must be true or false, exactly one of the alternatives will be executed.**
因为条件只能是真或假，所以两个分支中恰好有一个会被执行。

**The alternatives are called branches.**
这些选择路径称为分支（branches）。

### if / elif / else：多种情况

课件原文：

**Sometimes there are more than two possibilities and we need more than two branches.**
有时可能性超过两种，因此我们需要两个以上的分支。

**elif is an abbreviation of "else if".**
`elif` 是 `else if` 的缩写。

```python
if x < y:
    print("x is less than y")
elif x > y:
    print("x is greater than y")
else:
    print("x and y are equal")
```

解释：
1. 如果 x 小于 y，执行第一个分支。
2. 否则，如果 x 大于 y，执行第二个分支。
3. 其他情况就是两者相等，执行 else。

课件说明：`elif` 可以有多个；如果有 `else`，它必须放在最后；也可以没有 `else`。

### 嵌套 if：判断里面再判断

课件示例：

```python
speed = 95
mood = 'terrible'

if speed >= 80:
    print('License and registration please')
    if mood == 'terrible' or speed >= 100:
        print('You have the right to remain silent.')
    elif mood == 'bad' or speed >= 90:
        print("I'm going to have to write you a ticket.")
    else:
        print("Let's try to keep it under 80 ok?")
else:
    print("You're a slow driver")
```

理解：
- 先判断 speed 是否至少为 80。
- 如果是，进入内部判断。
- 内部再根据 mood 或 speed 决定输出哪句话。
- 如果 speed 小于 80，则执行最外层 else。

这就是嵌套条件判断：一个 if 里面还可以有另一个 if。

### 用 `find()` 结果判断是否找到内容

```python
string = 'Good bye'
result = string.find('ere')
print(result)

if result != -1:
    print('Success!')
else:
    print('Not found!')
```

`find()` 找不到时返回 -1。因此：
- `result != -1`：找到了。
- `result == -1`：没有找到。

## 22. Quick Exercise 3：找三个数中的最大值

课件原文：

**Define a function biggest(a,b,c) that takes three numbers a,b and c as input and returns the biggest number.**
定义函数 `biggest(a,b,c)`，接收三个数字，返回其中最大的数字。

课件提示：这是 Nested if problem，即嵌套 if 问题。

一种基础写法：

```python
def biggest(a, b, c):
    if a >= b and a >= c:
        return a
    elif b >= a and b >= c:
        return b
    else:
        return c
```

解释：
1. 先判断 a 是否同时不小于 b 和 c。
2. 如果不是，再判断 b 是否同时不小于 a 和 c。
3. 如果前两种都不是，那么 c 就是最大值。

测试：

```python
print(biggest(1, 2, 3))  # 3
print(biggest(4, 3, 1))  # 4
print(biggest(4, 8, 1))  # 8
```

## 24. While loop：while 循环

### 原文逐句翻译

**The while loop continues iterating until its condition stops being true.**
只要 while 循环的条件仍然为真，循环就会继续执行；当条件变为假时，循环停止。

### 示例一

```python
i = 0

while i < 5:
    i = i + 1
    print(i)
```

执行过程：

| 进入循环时 i | 执行 `i=i+1` 后 | 输出 |
|---:|---:|---:|
| 0 | 1 | 1 |
| 1 | 2 | 2 |
| 2 | 3 | 3 |
| 3 | 4 | 4 |
| 4 | 5 | 5 |

最终输出：

```text
1
2
3
4
5
```

当 i 变成 5 时，`i < 5` 不再成立，循环结束。

### 示例二：先打印，再增加

```python
i = 0

while i < 5:
    print(i)
    i = i + 1
```

输出：

```text
0
1
2
3
4
```

为什么和上一个例子不同？
因为这一次先输出 i，再让 i 加 1；上一个例子先加 1，再输出。

**记忆：循环内部语句的先后顺序会影响结果。**

### 无限循环警告

课件给出一个不要运行的例子：

```python
i = 0
while i != 11:
    i = i + 2
    print(i)
```

为什么会无限循环？
- i 从 0 开始。
- 每次增加 2。
- i 只会是偶数。
- 它永远不可能等于 11。
- 所以条件 `i != 11` 永远为 True。

如果不小心运行了无限循环，可以在 Jupyter 中使用 Kernel → Interrupt 停止执行。

### while 循环打印三次

```python
i = 0
while i < 3:
    print("Dance")
    i = i + 1
```

输出：

```text
Dance
Dance
Dance
```

### `break`：立即退出循环

```python
while True:
    print('Dance')
    break
```

`while True` 本来会一直循环，但 `break` 会立即终止循环，因此只打印一次。

### `continue`：跳过本轮剩余内容

课件示例：

```python
i = 0

while True:
    i = i + 1
    if i % 2 == 0:
        continue
    else:
        print("exit")
    if i >= 10:
        break
    print(i)
```

解释：
- 每次先让 i 加 1。
- 如果 i 是偶数，执行 `continue`，跳过本轮后面剩余的语句，直接进入下一轮。
- 如果 i 是奇数，执行 else 中的打印。
- 当程序运行到 `i >= 10` 时，满足条件就 `break`。

**记忆：**
- `break`：结束整个循环。
- `continue`：结束当前这一轮，继续下一轮。

### 函数练习：计算 0 到 n 的总和

课件原文：

**Write a function my_sum that uses a while loop to sum all numbers from 0 to n.**
编写函数 `my_sum`，使用 while 循环把从 0 到 n 的所有数字相加。

代码：

```python
def my_sum(n):
    i = mysum = 0

    while i != n + 1:
        mysum = mysum + i
        i += 1

    return mysum
```

以 `my_sum(5)` 为例：

```text
0 + 1 + 2 + 3 + 4 + 5 = 15
```

返回：

```text
15
```

解释：
- `i` 是当前正在加的数字。
- `mysum` 保存累计总和。
- 每次把 i 加到 mysum。
- `i += 1` 等价于 `i = i + 1`。
- 当 i 到达 n+1 时，循环停止。

### 阶乘 factorial

课件原文：

**Define a function called factorial(n).**
定义一个名为 `factorial(n)` 的函数。

阶乘的意思：
- 3! = 3 × 2 × 1 = 6
- 5! = 5 × 4 × 3 × 2 × 1 = 120

课件代码：

```python
def factorial(n):
    i = 1
    result = 1

    while i < n + 1:
        result = result * i
        i += 1

    return result
```

执行 `factorial(5)` 的过程：

| i | result 更新 |
|---:|---:|
| 1 | 1 × 1 = 1 |
| 2 | 1 × 2 = 2 |
| 3 | 2 × 3 = 6 |
| 4 | 6 × 4 = 24 |
| 5 | 24 × 5 = 120 |

最后返回 120。

### Quick Exercise 4：用循环计算级数

课件原题：

\[
4\sum_{k=1}^{10^6}\frac{(-1)^{k+1}}{2k-1}
\]

课件给出的展开形式：

\[
4\times(1-1/3+1/5-1/7+1/9-1/11+\cdots)
\]

翻译：从 k=1 开始，一直计算到 1,000,000；每一项的分母是 `2k-1`，正负号交替，最后把总和乘以 4。

思路：
- k 从 1 开始。
- 如果 k 为奇数，该项为正。
- 如果 k 为偶数，该项为负。
- 每次把当前项加到 result。
- k 每次增加 1。
- 最后乘以 4。

参考代码：

```python
k = 1
result = 0

while k <= 1000000:
    if k % 2 == 1:
        result = result + 1 / (2 * k - 1)
    else:
        result = result - 1 / (2 * k - 1)

    k = k + 1

result = 4 * result
print(result)
```

这里重点不是背结果，而是理解如何把数学求和写成循环。

## 25. For loop：for 循环

### 原文翻译

**For iterating over a collection or an iterator.**
`for` 用于遍历一个集合或可迭代对象中的元素。

通俗理解：
- `while` 更像是“只要条件成立，就继续做”。
- `for` 更像是“把列表里的每个元素依次拿出来处理”。

### 示例：计算列表所有数字之和

课件原文：

**Write a for loop to sum all numbers for [3, 41, 12, 9, 74, 15].**
编写一个 for 循环，计算列表 `[3, 41, 12, 9, 74, 15]` 中所有数字的总和。

代码：

```python
def listsum(numList):
    theSum = 0
    for i in numList:
        theSum = theSum + i
    return theSum

print(listsum([3, 41, 12, 9, 74, 15]))
```

结果：

```text
154
```

逐句解释：
- `theSum = 0`：先准备一个累计总和变量。
- `for i in numList`：依次取出列表里的每个数字。
- `theSum = theSum + i`：把当前数字加进总和。
- `return theSum`：返回最终总和。

### `continue`：跳过特定元素

课件示例：

```python
sequence = [1, 2, None, 4, None, 5]
total = 0

for value in sequence:
    if value is None:
        continue
    total += value

print(total)
```

解释：
- `None` 表示这里没有一个正常数值。
- 如果 value 是 None，就跳过本轮，不做加法。
- 其他数字都累计到 total。

结果：

```text
12
```

### `break`：遇到指定值就停止

课件示例：

```python
seq = [1, 2, 0, 4, 6, 5, 2, 1]
total_until_5 = 0

for value in seq:
    if value == 5:
        break
    total_until_5 += value

print(total_until_5)
```

解释：
- 从列表开头依次读取数字。
- 遇到 5 时，立即结束整个循环。
- 5 后面的数字不再处理。

计算：

`1 + 2 + 0 + 4 + 6 = 13`

输出：

```text
13
```

### 使用 for 统计列表元素数量

课件示例：

```python
basket = ['banana', 'apple', 'durian', 'orange', 'rambutan']

number = 0

for item in basket:
    number += 1

print(number)
```

结果：

```text
5
```

每从列表中取出一个元素，number 就增加 1，因此最终得到列表中的元素数量。

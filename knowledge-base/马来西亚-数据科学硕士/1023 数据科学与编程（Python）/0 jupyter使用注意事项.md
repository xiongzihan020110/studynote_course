- conda env list

## 2 Jupyter Notebook 快捷键大全（最常用优先使用）

建议按照下面的顺序练习：

1. **运行代码：** `Shift + Enter`
2. **切换模式：** `Esc` 和 `Enter`
3. **新建单元格：** `Esc` → `B`
4. **转换 Markdown：** `Esc` → `M`
5. **转换 Code：** `Esc` → `Y`
6. **删除单元格：** `Esc` → `D` → `D`
7. **查看函数帮助：** `Shift + Tab`
8. **代码补全：** `Tab`
9. **复制与粘贴单元格：** `C`、`V`
10. **中断或重启内核：** `I` → `I`、`0` → `0`

---

> **注意：** Jupyter Notebook 主要有两种模式：
>
> - **命令模式（Command Mode）**：单元格边框为蓝色，用于操作单元格。
> - **编辑模式（Edit Mode）**：单元格边框为绿色，用于编写和修改代码。
>
> `Esc` 进入命令模式，`Enter` 进入编辑模式。

## 3、最常用的快捷键

| 快捷键             | 功能                | 使用场景         |
| --------------- | ----------------- | ------------ |
| `Shift + Enter` | 运行当前单元格，跳到下一个单元格  | 最常用          |
| `Ctrl + Enter`  | 运行当前单元格，停留在当前单元格  | 反复测试代码       |
| `Alt + Enter`   | 运行当前单元格，并在下方新建单元格 | 连续编写代码       |
| `Esc`           | 切换到命令模式           | 管理单元格        |
| `Enter`         | 切换到编辑模式           | 修改代码         |
| `A`             | 在当前单元格上方插入单元格     | 命令模式         |
| `B`             | 在当前单元格下方插入单元格     | 命令模式         |
| `D`，连续按两次 `D`   | 删除当前单元格           | 命令模式         |
| `M`             | 将单元格转换为 Markdown  | 编写笔记         |
| `Y`             | 将单元格转换为 Code      | 编写 Python 代码 |

## 4、单元格操作快捷键

**使用前先按 `Esc`，进入命令模式。**

| 快捷键         | 功能               |
| ----------- | ---------------- |
| `↑` / `↓`   | 上下选择单元格          |
| `A`         | 在上方插入单元格         |
| `B`         | 在下方插入单元格         |
| `X`         | 剪切当前单元格          |
| `C`         | 复制当前单元格          |
| `V`         | 在下方粘贴单元格         |
| `Shift + V` | 在上方粘贴单元格         |
| `Z`         | 撤销单元格删除          |
| `D` → `D`   | 删除当前单元格          |
| `Shift + M` | 合并选中的单元格         |
| `M`         | 转换为 Markdown 单元格 |
| `Y`         | 转换为 Code 单元格     |

---

## 5、代码编辑快捷键

**使用前先进入编辑模式，按 `Enter`。**

| 快捷键                | 功能            | 说明                    |
| ------------------ | ------------- | --------------------- |
| `Tab`              | 代码补全、缩进       | 输入变量或函数时使用            |
| `Shift + Tab`      | 查看函数说明和参数     | 例如查看 `read_csv()` 的参数 |
| `Ctrl + /`         | 注释或取消注释选中的代码  | 具体取决于版本和键盘设置          |
| `Ctrl + Z`         | 撤销代码编辑        | 恢复上一步修改               |
| `Ctrl + A`         | 全选当前代码编辑区域的文本 | 注意不是全选所有单元格           |
| `Ctrl + ]`         | 增加缩进          | 部分版本适用                |
| `Ctrl + [`         | 减少缩进          | 部分版本适用                |
| `Ctrl + Shift + -` | 在光标处拆分单元格     | 经典 Notebook 常用        |

## 6、运行、停止与重启内核

| 快捷键             | 功能          | 使用场景        |
| --------------- | ----------- | ----------- |
| `Shift + Enter` | 运行当前单元格     | 日常运行代码      |
| `Ctrl + Enter`  | 运行当前单元格但不跳转 | 调试代码        |
| `Alt + Enter`   | 运行并新建单元格    | 连续写代码       |
| `I` → `I`       | 中断内核        | 命令模式，部分版本适用 |
| `0` → `0`       | 重启内核        | 命令模式，部分版本适用 |

**注意：**

- 中断内核会尝试停止正在执行的代码。
- 重启内核会清除当前 Python 会话中的变量和运行状态，未保存到文件的数据可能丢失。
- 执行快捷键前确认当前 Notebook 版本支持对应操作。

## 7、Markdown 单元格常用语法

在命令模式下按 `M`，即可把单元格转换为 Markdown 单元格。

### -. 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

### -. 文字格式

```markdown
**加粗文字**

*斜体文字*

~~删除线文字~~

`行内代码`
```

### -. 列表

无序列表：

```markdown
- 项目一
- 项目二
  - 子项目
```

有序列表：

```markdown
1. 第一步
2. 第二步
3. 第三步
```

### -. 超链接

```markdown
[Python 官网](https://www.python.org/)
```

### -. 插入图片

```markdown
![图片说明](图片链接)
```

### 6. 插入代码块

\`\`\`python
import pandas as pd

df = pd.read_csv("data.csv")
df.head()
\`\`\`

### -. 插入引用

```markdown
> 这是一段引用文字。
```

### -. 插入分割线

```markdown
---
```

### -. 插入表格

```markdown
| 姓名 | 年龄 | 专业 |
|---|---|---|
| 张三 | 20 | 数据科学 |
| 李四 | 22 | 计算机科学 |
```

## 10、快捷键使用注意事项

-. 命令模式与编辑模式下，同一个按键可能具有不同作用。

-. `A`、`B`、`M`、`Y`、`D` → `D` 等操作通常需要在命令模式下使用。

-. `Tab`、`Shift + Tab` 等操作通常在编辑模式下使用。

-. 不同版本的 Jupyter Notebook、JupyterLab 以及自定义键盘设置，可能会导致部分快捷键不同。

-. 如果快捷键无法使用，可以打开 **Help → Keyboard Shortcuts** 查看当前环境支持的快捷键。

**学习建议：** 初期先熟练掌握运行代码、插入单元格、切换 Markdown、代码补全这四类操作，再逐渐学习其他快捷键。

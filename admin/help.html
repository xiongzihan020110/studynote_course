知识库管理授权说明

只需在常用且可信的浏览器连接一次，以后打开管理页面会自动连接。

  1. 打开 GitHub 令牌创建页面。
  2. Token name 填写 Knowledge Admin；Resource owner 选择 xiongzihan020110。
  3. Expiration 选择适合自己的有效期。到期后需要重新创建令牌。
  4. Repository access 选择 Only select repositories，仅勾选 studynote_course。
  5. Permissions 点击添加仓库权限，选择 Contents，设为 Read and write。Metadata 保持默认；无需添加账户权限。
  6. 点击 Generate token，复制生成的令牌，返回管理页面，粘贴并点击“连接仓库”。不要将令牌发给他人或保存到公开仓库。

授权保存在当前浏览器的本地存储中。更换浏览器、使用无痕模式、清除网站数据、令牌过期或撤销后，需要重新连接。共用电脑使用完请点击“退出并清除授权”。

此设置仅影响在线管理页面，不修改 Obsidian 主动同步或每日自动同步的配置。
